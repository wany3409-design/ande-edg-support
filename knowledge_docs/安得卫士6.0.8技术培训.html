Encryption · 落地加解密

落地加解密

落地加解密策略支持指定本地路径、移动存储设备、网络共享路径、文件类型，实现配置在策略中的关联文件保存指定路径后自动加解密。

@ 代表移动存储设备，# 代表共享目录

默认优先级低于透明加解密策略，优先级支持调整

支持三种识别方式：路径识别 · 内容识别 · 截屏加密

Security · 安全隔离

安全隔离

  • 一个安全组 等于 一把密钥，最多256个安全组
  • 一个用户可隶属多个组，最多20个
  • 主组产生密文用此组密钥加密；副组支持阅读其他组密文
  • 已加密文件流转到其他组，可选择是否改变密钥，默认不变密钥

Security · 内容安全管控

内容安全管控

拷贝控制

开启后密文之间可以互相拷贝，密文无法拷贝到明文，明文可以拷贝到密文；支持关联进程例外和字符数控制设置，字符控制目前只能控制普通的文本类型，不能控制非文本类型，如图片等。
如控制除记事本外的其他关联进程只能向明文中拷贝200字节

联网控制

（WPS、Office 类自带的联网外发分享功能）：开启后密文进程的软件无法通过网络传输加密文件，支持配置关联进程例外，如控制除 winword 外的其他关联进程禁止联网分享文件

另存控制

开启后密文存储任意副本均强制加密，支持配置关联进程例外，如控制除记事本外的其他关联进程另存为全部强制加密

截屏及远程控制

开启后在打开密文的情况下，禁止截屏/录屏/远程软件对屏幕进行截图，如除 notepad 外的其他关联进程禁止截屏及远程分享

可通过流程审批方式在一段时间内可以投屏（即不控制）

插入控制

开启后密文无法插入到明文或其他非受控软件中

Network · 网络访问控制

网络访问控制

进程只能访问指定地址

表示进程列表中进程只能访问指定地址，此进程不允许再访问其他地址

进程不能访问指定地址

表示进程列表中指定进程不能访问指定地址，但可以访问其他地址

地址只能被指定进程访问

表示地址中设置的网络路径只能被指定进程列表中进程访问，未设置的进程不能访问此网络路径

指定的地址不能被指定进程访问

表示进程列表中设置的进程不能访问设置的网络路径；如果进程列表设置为空，则表示所有的进程都不能访问地址中设置的网络路径

进程与地址一一对应

指定进程只能访问指定网络，指定网络也不能被其他进程访问

驱动替换说明

驱动版本说明

驱动分为 release 和 debug 两个版本，debug 版本分为 2 种：

  • debug 版本：配合 DebugView 工具抓取，日志实时刷新，推荐使用
  • debugfile 版本：日志直接写入文件，目录 C:\Program Files (x86)\iAndSec\FileShield\DmpDbg，适合偶现问题，复现后提取日志

替换方法

  1. 将原来的驱动 MonSafe.sys 改名
  2. 选择对应操作系统的驱动版本（win11 使用 win10 的驱动），拷贝到 C:\Windows\System32\drivers 下，改名 MonSafe.sys
  3. 重启电脑

蓝屏问题排查

常见原因

  • 驱动版本与操作系统不匹配
  • 驱动文件损坏或替换不当
  • 与第三方软件冲突

排查方法

  • 查看系统事件日志
  • 使用 DebugView 抓取日志
  • 替换为 release 正式版驱动

DMP 提取

提取 dmp 文件，在 C:\Windows\MEMORY.DMP（建议压缩后再传输）。如果没有产生，先打开核心内存转存，等复现后再提取

Crypto · 加密逻辑

加密工作原理

加密流程

  • 文件写入时实时加密，读取时透明解密
  • 通过文件系统过滤驱动（mini-filter）拦截 I/O
  • 根据进程策略判断是否需要加解密
  • 密文标识头标记文件加密状态

解密流程

  • 受信进程读取密文 → 驱动自动解密 → 明文返回
  • 非受信进程读取密文 → 驱动返回密文数据
  • 外发/解密申请 → 审批通过后去除密文标识

加解密原理示意

Hook · 注入逻辑

HOOK 注入逻辑

注入方式

  • 通过驱动层 HOOK 系统 API，拦截文件 I/O 操作
  • 支持进程级注入，只对受信进程生效
  • HOOK 点包括 CreateFile、ReadFile、WriteFile 等

注入逻辑

  • 进程启动时检测策略 → 匹配则注入 HOOK DLL
  • HOOK 层区分读/写操作，按策略透明加解密
  • 非受信进程绕过 HOOK 层，返回原始数据

常见问题案例

1

客户端还是服务器？

解密失败
症状

客户端申请解密，审批员通过后，发现文件并没有解密成功。

原理

服务器仅下发消息，最终由客户端执行解密动作。文件被占用或编辑过的文件无法被解密。

排查

记录提交人、时间等信息，拷贝服务器日志给研发分析；客户端解密失败时检查文件是否被修改。

策略 · HOOK · 驱动 · 非问题？

卡死/闪退
症状

caseviews 软件打开文件编辑后，保存卡死或闪退。

原理

程序阻止了文件流回写，导致进程无法响应。可能涉及 HOOK 动作、加密中间文件、驱动适配、第三方冲突。

排查

去 HOOK 进程 → procmon 抓文件类型 → 抓 debug+procmon 日志给研发 → 明文停驱动验证。
